Display Helper — Free API Key & Setup Guide

Option A: Free Gemini API Key (Google AI Studio)

  1. Open Google AI Studio (aistudio.google.com/app/apikey) and sign in with a personal @gmail.com account.
  2. Click Create API key → select Create API key in a new project, then copy the key (starts with AIzaSy...).
  3. Paste it into the API Key field in the Display Helper popup and click Save Settings.
Fixing HTTP 403: Your project has been denied access:
Google’s automated anti-abuse filter often flags new free-tier projects under these conditions:
  • Turn OFF VPNs: Commercial VPNs or datacenter IPs trigger immediate project denial by Google.
  • Use a Personal Gmail: School (.edu) and Google Workspace accounts usually block API provisioning. Use an established personal @gmail.com account with a verified phone number and 2-step verification.
  • Create API key in a NEW project: In Google AI Studio, never reuse a flagged project. Always click "Create API key in a new project".
  • Verify Generative Language API is Enabled: Open Google Cloud Console API Library, select your project, and ensure Generative Language API is set to Enabled.
